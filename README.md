# Каргули — грузинский для жизни

MVP Telegram Mini App с текстом и необязательной озвучкой на React 19, TypeScript, Vite и Tailwind CSS 4. Работает и в обычном браузере.

## Запуск

Нужен Node.js 24+ (тесты используют встроенную поддержку TypeScript).

```bash
npm ci
npm run dev
```

```bash
npm test
npm run build
npm run preview
```

## Что работает

- 9 бытовых сценариев, 20 уроков, 80 слов и фраз; в каждом уроке 4 новые карточки и проверки.
- Числа 1–10 и практические заказы: четыре урока, два вида товара на витрине, маленький кофе и два пончика. Два длинных заказа собираются из отдельных плашек количества, размера и товара; повторяющиеся слова остаются отдельными кусочками. В шпаргалке — отдельный фильтр «Числа и заказ».
- Новые темы для долгого проживания: квартира и бытовые проблемы, автобус и метро, соседи и знакомства. В новых уроках все варианты первого теста предварительно показаны. [Источники и редакторские заметки](docs/content-sources.md).
- Сборка фраз из перемешанных плашек в разговорных уроках и заказах из двух позиций: убрать кусочек, очистить ответ, проверить, открыть транслит и пример. Подсказка и ошибка сохраняются в сессии и не дают балл за первую попытку; возврат к задаче не сбрасывает этот учёт. Проверяется восстановление фразы из урока, а не все допустимые порядки слов в грузинском.
- В заданиях с грузинскими вариантами ответа — транскрипция по запросу сразу для всех вариантов. На следующем вопросе скрыта. Подсказка сохраняется в сессии даже после скрытия и перезагрузки: такой ответ не повышает закрепление, фраза остаётся в повторении на сегодня. После ответа транскрипцию можно открыть без изменения результата.
- Шпаргалка всех фраз, поиск, категории, избранное, контрастный режим показа, копирование грузинского оригинала и ручное выделение при недоступности Clipboard API.
- Все 33 буквы с примерами; отдельная практика по две буквы: знакомство со звуком, подсветка в слове, грузинская озвучка слова и проверки в обе стороны. Отметки и подсветка появляются только после практики. Старые автоматические открытия не считаются проверкой; прогресс фраз сохраняется. Русский текст остаётся читаемым.
- Повторения: после верного ответа следующая дата через 1, 3 или 7 дней; ошибка возвращает фразу в очередь на сегодня. Второй верный ответ в другой день означает «закреплена». Повторные ответы в один день не повышают уровень.
- Локальный стрик по календарю устройства, сохранение шага урока и избранного, восстановление после повреждённых данных. Ключ localStorage: `karguli.progress.v1`.
- Светлая, тёмная и системная темы. Telegram WebApp SDK: тема и её обновление, BackButton, необязательная вибрация для поддерживаемых клиентов, отступы safe area.
- Короткие оригинальные звуки правильного/неверного ответа, перехода и завершения урока через Web Audio. Звуки включены по умолчанию после пользовательского нажатия; отключаются в панели звука в шапке.
- Только грузинская озвучка: 112 MP3 голосом Piper Natia для всех 80 слов и фраз, реплик диалога и слов-примеров алфавита. Русский перевод остаётся текстом.
- Рядом с обычным воспроизведением — кнопка с черепашкой: заново запускает ту же фразу или весь диалог на скорости 0,75× с сохранением высоты голоса. Повторное нажатие черепашки начинает запись сначала. Для остановки медленного воспроизведения есть отдельная кнопка.
- Настройки звуков и громкости сохраняются вместе с прогрессом. Озвучка запускается вручную, останавливается при смене карточки/экрана, закрытии модального окна или скрытии приложения. Обычное повторное нажатие на активную кнопку звука останавливает её.
- HTML Audio воспроизводит готовые записи без системного грузинского голоса. Если запись недоступна, резервный Web Speech API использует только грузинский голос; русский и другие языки не подставляются.

## Обновление озвучки

Аудиофайлы уже находятся в `public/audio/ka/`, синтез на сервере не требуется. После изменения учебных текстов:

```bash
node --experimental-strip-types scripts/prepare-audio.mjs
# В отдельной Python-среде: pip install piper-tts==1.8.0
# Скачать ka_GE-natia-medium.onnx и .onnx.json из rhasspy/piper-voices.
python scripts/generate-audio.py /path/to/ka_GE-natia-medium.onnx
```

Происхождение записей: `public/audio/NOTICE.md`. Модель и Python-движок не включены в приложение. Синтез выполнен локально по грузинским оригиналам. `npm test` проверяет полноту аудиозаписей, последовательность реплик, остановку, медленное повторение и отказ от русского голоса в резервном синтезе.

## Контент

`src/data/lessons.ts` содержит типы Phrase, Lesson, Step, AlphabetLetter и весь учебный контент. Фразы переиспользуются по постоянным ID. Весь контент имеет `editorialStatus: 'draft'`: он ещё не проверен преподавателем/редактором грузинского. Кириллическая запись приблизительна; приложение не проверяет произношение пользователя. Синтезированная грузинская озвучка пока не прошла проверку преподавателем. Перед учебным релизом нужна языковая редактура всех фраз, транскрипций, примеров и ситуаций.

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` проверяет тесты, собирает приложение и публикует `dist` при push в `main`. В Settings → Pages источник публикации должен быть **GitHub Actions**.

Адрес демо: https://kollase.github.io/karguli-miniapp/

В workflow задан `VITE_BASE_PATH=/${{ github.event.repository.name }}/`. Пути к аудио используют базовый адрес Vite, поэтому работают и в подкаталоге Pages, и на хостинге в корне домена. Для локальной проверки сборки Pages:

```bash
VITE_BASE_PATH=/karguli-miniapp/ npm run build
VITE_BASE_PATH=/karguli-miniapp/ npm run preview
```

Открыть `http://127.0.0.1:4173/karguli-miniapp/`. Обычная `npm run build` сохраняет базовый путь `/`.

## Подключение к Telegram

1. Разместить `dist/` на публично доступном HTTPS-хостинге. Приватный предпросмотр Sites с авторизацией не является готовым адресом для Telegram WebView.
2. В BotFather выбрать существующего или создать отдельного бота, настроить Main Mini App / menu button с HTTPS-адресом приложения.
3. Открыть приложение из бота и проверить тему, BackButton, safe area, копирование и HapticFeedback на реальных Android/iOS-клиентах. Бот и его настройки автоматически не создаются.

Сервер для учебного состояния не нужен. Токен бота во frontend не передаётся. Идентификация и серверная проверка initData не реализованы, поскольку защищённых серверных операций нет; при их добавлении initData требуется проверять на сервере.

## Ограничения MVP

Нет межустройственной синхронизации, полноценного офлайн-запуска, уведомлений, аналитики и подтверждённой языковой редактуры. Грузинская озвучка синтезированная; её произношение должен проверить преподаватель. Русский перевод отображается только текстом. Google Fonts и Telegram SDK загружаются с внешних источников, шрифты имеют системные fallback. При очистке localStorage прогресс удаляется. Дата/стрик зависят от часов устройства. Вторая новая сессия заменяет сохранённый незавершённый урок. Звук зависит от системной громкости, ограничений WebView и разрешения воспроизведения после жеста пользователя; аудио надо проверить на реальных Telegram iOS/Android.

## Проверка

`npm test` проверяет сохранение, восстановление повреждённых данных, календарные границы, стрик, повторения, защиту от накрутки закрепления за один день, идемпотентное завершение, полноту алфавита и корректность вариантов всех упражнений. `npm run build` запускает TypeScript и production-сборку.
